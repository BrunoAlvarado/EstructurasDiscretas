Estructuras Discretas

Nombre completo: Alvarado Ibáñez Bruno

Descripción

Este repositorio contiene las actividades, prácticas y proyectos de la asignatura de Estructuras Discretas.

El repositorio se encuentra organizado de acuerdo con las indicaciones establecidas para el curso. Cada práctica cuenta con su propia carpeta, dentro de la cual se almacenarán los archivos correspondientes a las actividades, ejercicios, documentación y demás entregables realizados a lo largo del semestre.

La organización del repositorio es la siguiente:

EstructurasDiscretas/
├── Practica1/
├── Practica2/
├── Practica3/
├── Practica4/
├── Practica5/
├── Practica6/
└── Proyecto/

Entorno de Haskell

La versión de Glasgow Haskell Compiler (GHC) utilizada para el desarrollo de las prácticas es:

GHC 9.10.3
